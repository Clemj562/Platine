Platine

Le vinyle de ce que tu écoutes sur Spotify.

  1. Installe Scriptable (gratuit, App Store).
  2. Ouvre-la, touche +, colle le script, nomme-le Platine, puis ▶︎ pour l’essayer.
  3. Écran d’accueil ou écran verrouillé → ajouter un widget Scriptable → touche-le → Script : Platine.

Ce script contient ton accès Spotify : ne le partage pas.
